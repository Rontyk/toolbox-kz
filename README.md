# ToolBox KZ — платформа проката в автоматических постоматах (CSS 447)

Полноценный веб-сервис: пользователь выбирает инструмент/технику, оплачивает (демо), получает QR-код + 6-значный код,
открывает ячейку постомата и возвращает предмет. Есть админ-панель.

## Запуск
Требуется Node.js ≥ 18.

    npm install
    npm start            # http://localhost:3000
    npm test             # 25 сквозных проверок API

База `toolbox.db` создаётся и заполняется демо-данными при первом запуске.

| Роль | Email | Пароль |
|---|---|---|
| Пользователь | demo@toolbox.kz | demo123 |
| Админ | admin@toolbox.kz | admin123 |

Переменные окружения: `PORT` (по умолч. 3000), `JWT_SECRET` (обязательно сменить в проде), `DB_PATH`.

## Стек и архитектура
- **Backend:** Node.js + Express, REST API, JWT-авторизация (bcrypt-хеши паролей), QR через `qrcode`.
- **БД:** SQLite через `sql.js` (чистый JS/WASM, файл `toolbox.db`): `users`, `lockers`, `cells`, `items`, `rentals` (внешние ключи, транзакции при аренде/возврате).
- **Frontend:** SPA на чистом JS (hash-router) в `public/`, без сборки.

## Бизнес-логика
- Тарифы: почасовой (1–24 ч) и посуточный (1–14 сут.), залог холдируется при оплате.
- Просрочка: ×1.5 от часового тарифа за каждый начатый час, удерживается из залога; остаток залога возвращается.
- Лимит: не более 3 активных аренд на пользователя; занятая ячейка не может быть арендована дважды (транзакция).
- Продление аренды (часы), возврат, история.
- «Эмулятор постомата» (`#/terminal`): ввод кода или QR-пейлоада открывает нужную ячейку — демонстрирует работу железа.
- Админка: выручка, загрузка ячеек, топ предметов/постоматов, CRUD предметов, добавление постоматов, раскладка предметов по ячейкам, список аренд и пользователей.

## API (кратко)
`POST /api/auth/register|login` · `GET /api/auth/me` · `GET /api/items`, `/api/items/:id`, `/api/lockers`, `/api/lockers/:id` ·
`POST /api/rentals` · `GET /api/rentals/mine` · `GET /api/rentals/:id/qr` · `POST /api/rentals/:id/extend|return` ·
`POST /api/locker/unlock` · `GET /api/admin/stats|rentals|users` · `POST|PUT|DELETE /api/admin/items` · `POST /api/admin/lockers` · `PUT /api/admin/cells/:id`

## Что не реализовано (честно для защиты)
Реальная оплата (эквайринг/Kaspi Pay) и холдирование залога, физическое управление замками (IoT), push/SMS-уведомления,
геолокационная карта. Это следующий этап после валидации спроса.
